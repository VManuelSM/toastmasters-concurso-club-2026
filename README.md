# Concurso del club 2026-2027

Deck de Toastmasters Pachuca para los concursantes del concurso del club del 19 de noviembre de 2026: quién concursa en cada categoría, qué formatos hay que llenar y qué califican los jueces.

Publicado en https://vmanuelsm.github.io/toastmasters-concurso-club-2026/

```bash
npm install      # requiere ../slidev-theme-toastmasters-pachuca
npm run dev      # abre el deck
./deploy.sh      # compila y publica en GitHub Pages
```

Las fotos de los concursantes van en `public/fotos/<slug>.jpg`; si falta alguna, la lámina muestra las iniciales.
